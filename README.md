# Ambo University Photo Gallery

Welcome to the Ambo University Photo Gallery! This project is a responsive, visually appealing website designed to showcase the beautiful moments, memories, and architectural landmarks of our university campuses.

## 🌟 Features
* **Home Page:** A comprehensive grid displaying all photos, equipped with a full-screen lightbox viewer for an immersive experience.
* **Categorized Collections:** Photos are neatly organized into specific albums (Woliso Campus, HHC, and Main Campus) for easy browsing.
* **Fully Responsive:** The layout is optimized to look great on desktops, tablets, and mobile phones.
* **Modern UI:** Features a clean design with a custom blue header and a professional dark-themed footer.

## 🛠️ Technologies Used
This project was built using standard web development technologies:
* **HTML5:** For the semantic structure of the web pages.
* **CSS3:** For styling, responsive layouts (Flexbox & Grid), and visual effects.
* **JavaScript (Vanilla):** For interactive features, including the lightbox navigation, dynamic image rendering, and password-protected albums.

## 📂 Project Structure
* `index.html` - The main landing page and photo gallery.
* `about.html` - Information about the gallery.
* `gallery.html` - The categorized photo collections.
* `contact.html` - Contact information page.
* `style.css` - Contains all the styling for the website.
* `script.js` - Handles the interactive logic and image viewing.
* `images/` - A folder containing all the photographs used in the gallery.

## 🚀 How to View the Project
You can view the live website by visiting the GitHub Pages link, or you can run it locally by downloading the project files and opening `index.html` in any web browser.
